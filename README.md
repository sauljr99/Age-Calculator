Age Calculator

This is a simple age calculator I built using Python and Tkinter.
You type in your name, birth year, month, and day, then hit the
"Calculate Age" button and it tells you how old you are in years.

Language: Python
Library: Tkinter (for the GUI window and widgets), datetime (to do the age math)

Notes:
- Make sure you have Python installed to run this.
- Just run the .py file and the window should pop up.
- The age is shown as a decimal (e.g., 20.75 years).
